# Finding the Hypotenuse of a Right Triangle
## Description
* This program calculates the hypotenuse of a right triangle using functions
from the math library.
## How to Run
1. * Open the pycharm.
2. * Find the program 
3. * Run the program.
4. * Input the length of side a and b.
5. * Check the answer.
## Input Needed
* Length a and b of the specific triangle
## Sample Output
* Enter the length of side a: 6
* Enter the length of side b: 8
* The hypotenuse is: 10.00
